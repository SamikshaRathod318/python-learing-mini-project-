*What is a decorator in Python?*

A decorator is a function that adds extra functionality to another function without changing its original code.

In simple words, a decorator modifies or extends what a function does.

Decorators are written using the @ symbol.

1. Timing Function Execution

Measure how much time a function takes to execute.

2. Debugging Function Calls

Print information whenever a function is called.

3. Cache Return Values

Store previous results so repeated calls with the same arguments can reuse the result instead of recalculating it.
